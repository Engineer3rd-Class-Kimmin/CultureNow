# 검증 현황과 다음 실험

## 현재까지 확인한 내용

기획 단계에서 일반인 27명을 대상으로 소규모 예비 설문을 진행했습니다. 목적은 시장 규모를 추정하는 것이 아니라, 문제 경험이 실제로 존재하는지와 MVP에서 어떤 조건을 우선해야 하는지 확인하는 것이었습니다.

### 주요 결과

| 항목 | 응답 |
|---|---:|
| 정보를 한 번에 확인하기 어렵거나 여러 서비스를 추가로 확인한 경험 | 20명 (74.1%) |
| 상황 기반 추천 서비스 이용 의향 긍정 | 20명 (74.1%) |
| 조건에 맞는 활동을 소수 후보로 압축한 방식 선호 | 19명 (70.4%) |
| 지도·길찾기·예약 연결이 필요하거나 유용 | 22명 (81.5%) |

추천에서 중요하게 본 조건은 다음과 같았습니다.

| 조건 | 응답률 |
|---|---:|
| 위치 및 이동시간 | 77.8% |
| 이용 가능 시간 및 운영시간 | 70.4% |
| 이용요금·예산 | 55.6% |
| 개인 관심분야·선호도 | 55.6% |
| 예약 필요 여부 | 48.1% |
| 날씨 및 실내·야외 여부 | 44.4% |
| 혼자 또는 동행 참여 가능 여부 | 44.4% |

이 결과는 취향 개인화보다 시간, 거리, 운영 여부를 먼저 구현해야 한다는 우선순위를 정하는 데 사용했습니다.

## 해석의 한계

- 27명은 전체 시민을 대표하기에 작은 표본입니다.
- 연령, 지역, 직업별 균형을 갖춘 표집이 아닙니다.
- 실제 화면을 사용한 행동 측정이 아니라 설명을 읽고 답한 의향 조사입니다.
- 이용 의향이 실제 반복 이용이나 결제로 이어진다고 볼 수 없습니다.

따라서 이 수치는 성과가 아니라 **다음 실험을 설계하기 위한 방향성**입니다.

## 다음 검증 1: 데이터 적합성

한 지역과 2~3개 API를 정해 200개 안팎의 활동 후보를 수집합니다.

확인 항목:

- 운영시간, 가격, 좌표, 예약 링크의 채움률
- 같은 장소·행사의 중복 비율
- 원천 페이지와 API 값의 불일치율
- 실제 서비스에 쓰기 어려운 오래된 데이터 비율

통과 기준은 구현 전에 고정합니다. 핵심 필드가 부족하면 데이터 원천을 늘리기보다 추천 범위를 좁히는 판단도 포함합니다.

## 다음 검증 2: 실행 가능성 판정

시간·위치·예산이 다른 시나리오를 만들고 사람이 판정한 정답과 엔진 결과를 비교합니다.

- 명백히 불가능한 후보의 제거율
- 가능한 후보를 잘못 제거한 비율
- `확인 필요` 처리의 적절성
- 상위 후보의 추천 이유가 데이터와 일치하는지

초기에는 정교한 점수보다 거짓 양성, 즉 실제로 갈 수 없는 장소를 추천하는 문제를 먼저 줄입니다.

## 다음 검증 3: 사용성 비교

동일한 활동 탐색 과제를 기존 검색 방식과 CultureNow 프로토타입으로 각각 수행합니다.

- 선택까지 걸린 시간
- 방문한 페이지 수
- 최종 선택의 실행 가능 여부
- 추천 이유에 대한 이해도
- 선택 확신과 재사용 의향

의향만 묻지 않고 실제 선택 행동과 소요시간을 기록합니다.

## 다음 검증 4: 현장 연결

길찾기·예약 링크 이동 이후의 행동을 가능한 범위에서 확인합니다. 클릭을 이용 완료로 간주하지 않고, 자발적 이용 확인이나 협력기관 집계와 대조합니다.

## 현재 주장할 수 있는 범위

### 확인됨

- 정보 탐색의 불편을 경험한 응답자가 예비조사에서 다수였음
- 응답자는 취향보다 위치·이동시간과 운영시간을 우선 조건으로 선택함
- 공공 문화·체육·관광 분야에 연계 검토 가능한 데이터 원천이 존재함

### 아직 가설

- CultureNow가 기존 검색보다 결정 시간을 줄임
- 실행 가능성 점수가 실제 이용 가능성을 정확히 설명함
- 추천이 공공자원의 실제 이용 증가로 이어짐
- 지자체·기관이 분석 및 운영 기능에 비용을 지불함

이 구분을 유지하는 것이 이후 MVP 결과를 과장 없이 평가하는 기준입니다.
