# 사업 모델과 KPI

## 사업화의 기준

CultureNow의 기본 탐색·추천 기능은 시민이 공공서비스에 접근하는 입구입니다. 이 기능을 유료 구독으로 잠그기보다, 공공기관과 지역 서비스가 이용 연결의 가치를 구매하는 구조를 우선 검토했습니다.

아래 내용은 확정된 매출모델이 아니라 검증해야 할 사업 가설입니다.

## 이해관계자별 가치

| 대상 | 현재의 어려움 | CultureNow가 제공할 가치 |
|---|---|---|
| 시민 | 여러 사이트에서 조건을 다시 확인 | 현재 상황에 맞는 소수 후보와 행동 연결 |
| 지자체·공공기관 | 자원을 홍보해도 실제 이용 전환을 알기 어려움 | 추천 노출, 이동·예약 연결, 지역 수요 분석 |
| 공공시설 운영자 | 생활권 이용자에게 적시에 노출되기 어려움 | 빈 시간대와 저이용 프로그램의 발견 가능성 확대 |
| 민간 예약·체험 서비스 | 구매 의도가 있는 사용자를 만나야 함 | 조건이 맞는 활동에 한정한 연결 |

## 수익모델 가설

### B2G

- 지자체별 문화·체육·관광 정보 통합 추천
- 지역 맞춤형 화면과 운영·유지관리
- 저이용 자원과 시간대별 수요 분석
- 데이터 누락·오류·갱신 필요 항목 리포트

먼저 확인할 것은 기관이 “AI 추천” 자체에 비용을 지불하는지가 아니라, 기존 자원의 이용률과 시민 접근성을 측정할 수 있는지입니다.

### B2B

- 민간 예약·체험 서비스 연결
- 지역 서비스 사업자 대상 추천 API
- 실제 이용 전환이 확인되는 경우의 제휴 수익

추천 순위를 수익성 때문에 왜곡하면 서비스의 신뢰를 잃을 수 있습니다. 제휴 결과는 명확히 구분하고, 실행 가능성 판정과 광고·제휴 로직을 분리해야 합니다.

### B2C

기본 추천은 무료를 전제로 합니다. 유료 기능을 만들더라도 초기 MVP의 핵심 가설에는 포함하지 않습니다. 시민용 구독보다 공공서비스 이용 활성화와 기관용 분석의 지불 의사를 먼저 확인합니다.

## 핵심 KPI

### 사용자 편익

| 지표 | 정의 | 확인하려는 것 |
|---|---|---|
| 결정 소요시간 | 첫 입력부터 후보 선택까지 걸린 시간 | 검색 부담이 실제로 줄었는가 |
| 추천 선택률 | 결과 중 하나를 선택한 세션 비율 | 후보가 행동 가능한 수준이었는가 |
| 길찾기 연결률 | 길찾기 버튼을 누른 세션 비율 | 추천이 이동 의사로 이어졌는가 |
| 예약·안내 이동률 | 원 페이지로 이동한 세션 비율 | 정보 확인 또는 예약으로 이어졌는가 |
| 재사용률 | 일정 기간 내 다시 사용한 비율 | 일회성 호기심을 넘었는가 |

### 추천 품질

| 지표 | 정의 |
|---|---|
| 실행 불가 노출률 | 운영 종료, 시간·예산 초과 결과가 노출된 비율 |
| 정보 확인 필요 비율 | 핵심 필드가 비어 재확인이 필요한 결과 비율 |
| 추천 이유 동의율 | 사용자가 추천 근거를 납득한다고 응답한 비율 |
| 실제 이용 확인률 | 선택 이후 이용이 확인된 비율 |

### 공공적 성과

- 저이용 시설·프로그램의 추천 노출과 이용 연결
- 지역·시간대별 미충족 수요
- 원천 데이터 오류 또는 갱신 필요 항목 발견
- 기존에 알지 못했던 생활권 자원 선택 비율

## KPI 해석 시 주의점

클릭은 실제 이용과 다릅니다. 길찾기나 예약 페이지 이동만으로 성과를 확정하지 않고, 가능한 범위에서 이용 완료 또는 운영기관 집계와 대조해야 합니다. 또한 추천 노출을 늘려 발생한 변화와 계절·행사·홍보 효과를 구분할 비교 기준이 필요합니다.

## 우선 검증할 사업 질문

1. 시민은 일반 검색보다 이 방식으로 더 빨리 활동을 고르는가
2. 기관은 조회수보다 이용 연결과 데이터 품질 리포트에 가치를 느끼는가
3. 지역 단위로 필요한 데이터 정비 비용이 감당 가능한가
4. 민간 연계가 공공서비스 추천의 중립성을 해치지 않고 운영 가능한가
